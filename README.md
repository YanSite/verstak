# Верстак — Концепт сайта мастерской кожаных вещей

Концепт команды «Есть что показать»: так может выглядеть онлайн мастерская кожаных вещей.
Бренд, цены, имя мастера, сроки и условия придуманы, это не сайт реального бизнеса.
Корзина условная: заказы здесь не принимаются.

Статический сайт без сборки: `index.html`, шрифты, изображения. Открывается через любой веб-сервер.
Для показа без смены настроек: `#lite` — облегчённая версия, `#calm` — без движения.
